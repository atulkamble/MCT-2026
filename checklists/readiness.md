# Renewal assessment readiness

## Decide on route
- [ ] Check recognized MTM session count in MCT Portal → My Profile
- [ ] Understand six genuine eligible deliveries are a possible alternative
- [ ] Understand assessment opt-in cannot be reversed to the MTM route
- [ ] Verify MCT-linked email access and at least one active Microsoft certification

## Prepare
- [ ] Read [MCT Terms](https://aka.ms/MCT_Terms)
- [ ] Read [official Teach-back Slides](https://aka.ms/Teachback-Slides)
- [ ] Read [official Rubric](https://aka.ms/MCT-Rubric)
- [ ] Read [Yoodli job aid](https://aka.ms/Yoodli_Job_Aid)
- [ ] Check actual allowed topics, timing and materials
- [ ] Test webcam, microphone, speakers, screen sharing and internet
- [ ] Rehearse an explanation and demo

## Complete
- [ ] Budget roughly 45–90 minutes
- [ ] Register with MCT email and open Yoodli → My Learning
- [ ] Complete all 10 modules sequentially
- [ ] Break only between modules
- [ ] Program Agreement Quiz ≥70% in one attempt
- [ ] Teach-back ≥70%; best of first two attempts
- [ ] Verify program shows complete

## Finish
- [ ] Allow up to 72 business hours for assessment results
- [ ] Pay the annual MCT fee when prompted
- [ ] Confirm renewed MCT status
