# MCT 2026–2027 | Renewal Preparation

Unofficial, original study materials for Microsoft Certified Trainer (MCT) renewal. Prepared using the user's November 2026 renewal portal notices, September 2026 MTM guide, and the **MCT Renewal Assessment Information Guide**.

> **Not affiliated with or endorsed by Microsoft or Pearson.** Practice questions below are **not official assessment questions**. Always use the official current Program Agreement, teach-back slides and rubric.

## Quick facts

| Assessment | Requirement |
|---|---|
| MCT eligibility cohort | Expiring between **1 Oct 2026 and 31 May 2027** |
| Estimated assessment time | **45–90 minutes**, self-paced |
| Modules | **10**, completed sequentially in Yoodli → My Learning |
| Program Agreement Quiz | **≥70%**, **one counted attempt** |
| Live AI-moderated teach-back | **≥70%**, best of **first two attempts** |
| Certification check | At least **one active Microsoft certification** |
| Full assessment retake | **None**, per supplied guide |
| Results | Allow **up to 72 business hours**, then pay annual fee |

**Two routes:** Deliver and log **six real, eligible MTM classes** (custom courses may count), **or** opt into the assessment after submitting the renewal form. **Assessment opt-in is irreversible**: you cannot subsequently return to six MTM sessions. MTM records can take up to **14 days** to sync. Neither the MTM guide nor renewal form provided specifies a minimum class duration; verify short-session eligibility with Microsoft.

## Preparation sequence

1. Read the current [MCT Program Agreement](https://aka.ms/MCT_Terms). Use the original quiz to check **process knowledge**, not as a substitute for the agreement.
2. Read the [official teach-back slides](https://aka.ms/Teachback-Slides), [rubric](https://aka.ms/MCT-Rubric), and [Yoodli job aid](https://aka.ms/Yoodli_Job_Aid).
3. Rehearse a **short illustrative** Azure VM or Docker lesson. Official topic, materials and timing override these examples.
4. If choosing the assessment, submit the application via the [MCT Portal](https://aka.ms/mctportal); watch your MCT-linked email for the Yoodli invite.
5. Launch the assigned sequence under **My Learning**. Take breaks **between**, never during, scored activities.
6. After passing, verify the result in the portal and complete the annual fee.
